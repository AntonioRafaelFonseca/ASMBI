# ASMBI

ASMBI (Assembly By an Idiot) is a small assembly-like language and emulator
written in C++. It gives you a compact way to experiment with registers,
memory, syscalls, branching, and a simple pixel display.

Programs are written as `.asmbi` text files and run by the emulator. The
optional Raylib display provides a 128 × 64 RGB565 framebuffer and basic
keyboard input.

For the full build instructions, language reference, syscall list, memory map,
display behavior, and examples, see the [detailed documentation](./DOCS.md).
